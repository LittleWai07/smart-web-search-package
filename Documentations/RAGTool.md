### Introduction

- The RAGTool module provides the RAG and KnowledgeBase tools for data embedding and matching

---

### Classes

There are these classes in the TavilySearch module:

- `RAGTool`: This class is for RAG (Retrieval-Augmented Generation) to embed and match data.
- `_KnowledgeBase`: This class is for managing a knowledge base.
- `_KnowledgeBaseSet`: This class is for managing a set of knowledge bases.
